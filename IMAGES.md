# Images to curate

Put each file in `public/images/`, named **exactly** as the slot id (any of .jpg .jpeg .png .webp .avif). Pages pick it up on the next build; nothing else to change. An empty slot shows nothing on the site; `/system/images` lists every slot.

**P0** = needed for launch · **P1** = makes the page feel finished · **P2** = nice to have. Rights: *official* = cited evidence, small and credited (see PRD §10.2); *public-domain* and *photo* need the source named: add a `credit:` line to that slot in `content/images.yaml` and it appears under the picture.
